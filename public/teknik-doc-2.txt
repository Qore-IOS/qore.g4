DEVICE TECHNICAL KNOWLEDGE BASE

1. DEVICE OVERVIEW

•	Device family: Roche cobas® 8000 modular analyzer series; ayrıca yüklenen güncel cobas® pro integrated solutions dokümanından karşılaştırmalı modül bilgileri çıkarılmıştır.
•	System purpose: Klinik kimya, ISE ve immünoloji testlerinin yüksek hacimli, modüler, otomatik in-vitro diagnostik analiz platformunda yürütülmesi.
•	Core architecture: cobas 8000 sistemi iki ana bileşenden oluşur: analitik modüller, kontrol ünitesi ve core bileşenleri içeren instrument; ayrıca instrument ile host/LIS arasında gerçek zamanlı veri koordinasyonu yapan cobas 8000 data manager.
•	Detected cobas 8000 modules: Core unit, control unit, data manager, ISE module, c 701, c 702, c 502, e 801, e 602.
•	Detected cobas pro analytical units: SSU/SB, ISE v1, ISE neo, c 503, c 703, e 801.
Fluidic architecture
•	Sample/reagent aspiration and dispensing via syringes, probes, sippers, nozzles and tubing.
•	ISE pathway: ISE Internal Standard, ISE Diluent, ISE Reference Electrolyte, dilution vessel, electrode block, pinch valve, sipper syringe, drain port.
•	cobas c pathway: reagent probes, reaction cells, incubation bath, cell wash solutions CellCln1/CellCln2, NaOHD/SMS/ECO-D.
•	cobas e pathway: ProCell, CleanCell, PreClean, sipper flow paths, AssayCup/AssayTip handling, microbeads mixing, detection unit.
Mechanical architecture
•	Rack transport, reagent loading, sample pipetting, reagent pipetting, reaction disk movement, reagent disk movement, mixer motion, sipper nozzle movement, magazine gripper/lifter/feeders, cap opener, pre-wash gripper, reagent loader.
•	Maintenance mode can switch off selected motors so probes and mechanical parts can be moved manually without powering off the instrument.
Electronic architecture
•	Control unit PC, data manager PC/server, barcode/RFID readers, sensor circuits, interlock switches, photometer system, ECL detection electronics, liquid level/clot detection signal systems.
•	Operators are explicitly not responsible for PCB-level electrical troubleshooting unless instructed by Roche Service.
Software control structure
•	Instrument UI controls maintenance, alarms, reagent registration, calibration/QC workflows, sample processing, module masking, data alarms, reruns, backup, parameter read/write and software-controlled maintenance.
•	Maintenance actions can be grouped into maintenance types and automated via maintenance pipes.

2. MODULES AND SUBSYSTEMS

Core Unit / Sample Supply / Rack Transport
•	Purpose: Rack input/output, STAT/routine rack routing, sample tracking, sample buffer and transport line coordination.
•	Connected systems: Barcode readers, rack sensors, host/LIS via data manager, analytical modules.
•	Sensors used: Barcode reader, rack presence/position sensors, transport line sensors.
•	Motors/actuators used: Rack transport motors, loading/unloading mechanisms.
•	Fluidic connections: None directly except sample containers delivered to pipetting positions.
•	Common failures: Rack jam, barcode read failure, rack priority/transport error, sample database mismatch.
•	Maintenance requirements: Rack/rack tray cleaning, barcode reader surface cleaning; cobas pro maintenance list includes cleaning racks, rack trays and 2D barcode reader surface.
Control Unit
•	Purpose: User interface, instrument control, maintenance execution, alarm display, parameter management.
•	Connected systems: Analytical modules, data manager, storage media, printer/reporting.
•	Software functions: Logon, startup, shutdown, maintenance pipes, alarm monitoring, calibration/QC ordering, sample processing.
•	Electronic boards: PC hardware; PCB replacement/troubleshooting reserved for Roche Service.
•	Common failures: Software freeze, incorrect parameters, download issues, backup/storage media issues.
•	Maintenance: Data backup, database backup, parameter read/write, program update.
cobas 8000 Data Manager
•	Purpose: Real-time data coordination between instrument and host/LIS.
•	Connected systems: Instrument, host/LIS, QC/calibration/result workflows.
•	Common failures: LIS communication issues, parameter download errors, result forwarding problems.
•	Security dependencies: Access control, validated software updates, authorized external devices.
ISE Module / ISE v1 / ISE neo
•	Purpose: Na⁺, K⁺, Cl⁻ measurement by ion-selective electrode technology.
•	Connected systems: Sample pipetter, dilution vessel, electrode block, reference electrode, reagent bottles/drawer, degasser, drain port.
•	Sensors used: Liquid short sensor, pressure sensor for clot detection, electrode signal system, liquid level detection.
•	Motors/actuators: Sample pipetter, syringes, sipper syringe, pinch valve.
•	Fluidic connections: ISE Internal Standard, ISE Diluent, ISE Reference Electrolyte, sample syringe, dilution vessel, electrode block, drain.
•	Common failures: Air in sipper syringe, low ISE internal standard, low chloride, ISE.E / ISE.N data alarms, IStd.E calibration alarm.
•	Calibration dependencies: ISE Low, ISE High, ISE S3 according to package insert; electrode condition and reference electrolyte stability.
•	Maintenance: Daily/weekly/monthly/every 2 months/quarterly/6-month/as-required maintenance for ISE module in cobas 8000; cobas pro includes cleaning sample probe, sonic wash station, reagent drawer/compartment, checking vacuum pump, ISE system wash.
c 701 / c 702 / c 502 Clinical Chemistry Modules
•	Purpose: Photometric clinical chemistry tests using reaction cells, reagent probes, mixers, incubation bath and photometer.
•	Connected systems: Reagent disks/cassettes, reaction disk/cells, reagent probes, sample pipetter, photometer, incubation bath, wash station.
•	Sensors used: Photometer output, cell blank monitoring, liquid detection/clot detection, temperature/incubation monitoring.
•	Motors/actuators: Reaction disk motor, reagent disk motor, reagent/sample pipetter motors, ultrasonic mixers.
•	Fluidic connections: Deionized water, NaOHD, CellCln1, CellCln2, ECO-D, rinse/wash flow, incubation bath water.
•	Common failures: Cell blank deviation, photometer lamp failure, dirty reaction cells/probes, air in syringes, incubation bath issues.
•	Calibration dependencies: Photometric test calibration, reagent lot/pack status, cell blank quality, lamp stability.
•	Maintenance: Photometer check, cell blank measurement, incubation water exchange, wash reaction parts, cell detergent prime, incubator bath cleaning, change reaction cell, change photometer lamp.
e 801 / e 602 Immunology Modules
•	Purpose: Electrochemiluminescence immunoassay processing using reagent pipetters, sample pipetter, sipper stations, ProCell/CleanCell, PreClean and consumable handling.
•	Connected systems: Reagent manager/loader, RFID readers, AssayCup/AssayTip magazines, sipper station, detection unit, pre-wash station.
•	Sensors used: Reagent short sensors, liquid level detection, clot detection, RFID readers, reagent loader sensors.
•	Motors/actuators: Reagent loader, reagent pipetters, sample pipetter, cap opener, bead mixer, magazine gripper/lifter/feeder, sipper gripper, pre-wash gripper.
•	Fluidic connections: ProCell, CleanCell, PreClean, sipper nozzles, PC/CC cups, aspiration pipes, rinse station.
•	Common failures: Reagent loader failure, reagent cassette handling failure, reagent short sensor alarm, sipper LLD failure, sample pipetting/clot detection failure.
•	Maintenance: Daily, every 2 weeks, quarterly/as-required depending on module; e 801 includes CleanCell/PreClean aspiration pipe cleaning, cooling filter cleaning, ProCell/ECL sipper flow path cleaning.

3. SOFTWARE SYSTEMS

Instrument UI / Overview Menu
•	Purpose: Module state monitoring, alarms, reagent status, masking, maintenance execution.
•	Affected hardware: All analytical modules.
•	Related errors: System alarms, data alarms, reagent masking, module stop alarms.
•	Dependencies: User logon, correct module status, standby/operation modes.
Data Manager / LIS Communication
•	Purpose: Coordinates data in real time between instrument and host/LIS.
•	Affected hardware: Control unit, data manager PC/server, host network.
•	Related errors: Download procedure errors, incorrect parameters, result transfer problems.
•	Dependencies: Host connection, network security, parameter versioning.
Maintenance Pipe System
•	Purpose: Automates groups of maintenance actions; supports Power Up Pipe and Start Up Pipe functions.
•	Affected hardware: All modules, depending on selected maintenance pipe.
•	Related errors: Overdue maintenance, failed maintenance action, module not in required mode.
•	Dependencies: Standby/masked mode, maintenance type intervals, correct consumables.
Calibration Review / Calibration Status
•	Purpose: Shows calibrator status and last calibration test details.
•	Status codes: P = processing, F = failed, S = successful. Calibration may be invalid if canceled due to sample clot or insufficient sample.
•	Affected hardware: ISE, cobas c modules, cobas e modules.
•	Related errors: Calibration alarms including IStd.E, Dup.E, Diff.E.
•	Dependencies: Calibrator lot, reagent pack lot/sequence, reagent status, pipetting success.
Alarm and Rerun Logic
•	Purpose: Detects data alarms, system alarms and conditions generating automatic reruns.
•	Affected hardware: Sample/reagent pipetting, photometer, ISE electrodes, ECL detection.
•	Related errors: H/L alarms, linearity, repeat limit, sensitivity limit, substrate depletion, ISE.E, ISE.N, ReagEx.
•	Dependencies: Application settings, rerun settings, repeat limits, QC/calibration status.

4. MECHANICAL SYSTEMS

Sample Pipetter / Sample Probe
•	Function: Aspirates/dispenses patient samples, calibrators and QC material.
•	Movement type: Vertical/horizontal robotic pipetting.
•	Connected systems: Sample syringe, pressure sensor, LLD, clot detection.
•	Common failures: Probe clogging, clot detection alarm, LLD low voltage, misalignment.
•	Maintenance: Probe cleaning/replacement; cobas pro lists sample probe replacement for ISE, c 503, c 703.
•	Calibration impact: Pipetting errors affect calibration, QC and sample results.
Reagent Pipetters / Reagent Probes
•	Function: Transfer reagents to reaction cells or assay vessels.
•	Movement type: Robotic aspiration/dispense.
•	Connected systems: Reagent syringes, reagent disk/pack, rinse station.
•	Common failures: Carryover, clogging, insufficient wash, reagent short alarms.
•	Maintenance: Wash Reaction Parts, reagent probe cleaning, reagent pipetting checks.
Reaction Disk / Reaction Cells
•	Function: Holds reaction cells for photometric measurements.
•	Movement type: Rotary indexing.
•	Connected systems: Reagent probes, sample probe, mixers, photometer, incubation bath.
•	Common failures: Dirty cells, damaged cells, abnormal blank, disk motor issue.
•	Maintenance: Cell Blank Measurement; Change Reaction Cell switches off reaction disk motor so cells can be exchanged without powering off.
Photometer / Lamp Assembly
•	Function: Measures absorbance in reaction cells.
•	Movement type: Optical/electronic measurement, lamp replacement mode.
•	Common failures: Lamp deterioration, abnormal photometer output, cell blank shifts.
•	Maintenance: Photometer Check measures cell blank value of reaction cell no. 1; Cell Blank Measurement flags reaction cells differing by >0.1 absorbance units from reaction cell no. 1.
Sipper Systems
•	Function: Aspirate diluted ISE sample/internal standard or ECL liquids into measurement path.
•	Connected systems: Syringes, electrode block or ECL detection, liquid level detection.
•	Common failures: Air, clogging, LLD failure, low signal.
•	Maintenance: Sipper check; e modules check ECL sipper nozzle movement and LLD function.
Reagent Loader / Reagent Handling
•	Function: Loads and handles reagent packs/cassettes.
•	Movement type: Loader transport and handling motion.
•	Connected systems: RFID readers, reagent manager, sensors.
•	Common failures: Loading failure, RFID reading error, reagent pack handling error.
•	Maintenance/diagnostics: Reagent Loader Check verifies loader movement, sensors and RFID readers; Reagent Handling Check checks all components used for reagent cassette handling.

Photometer Electronics

6. SENSORS AND DETECTION SYSTEMS

Pressure Sensor / Clot Detection
•	Sensor type: Pressure-based flow sensor.
•	Purpose: Detect sample clot in sample pipetter flow path.
•	Trigger conditions: Abnormal aspiration/dispense pressure.
•	Failure symptoms: Clot alarms, insufficient sample, calibration/sample interruption.
•	Related components: Sample syringe, sample probe, tubing.
•	Cleaning/replacement: Clean or replace sample probe; inspect tubing and syringe.
Liquid Level Detection / LLD
•	Sensor type: Liquid level detection signal system.
•	Purpose: Detect liquid surface during pipetting/sipper operation.
•	Trigger conditions: Low voltage or failure to detect level.
•	Failure symptoms: Liquid level sensor alarm; sample probe mechanism may remain in vertical upper position.
•	Affected modules: ISE, c 503/cobas c, e modules.
•	Corrective actions: Check probe cleanliness, liquid presence, wiring/sensor status, alarm remedy.
Liquid Short Sensor
•	Sensor type: Reagent presence/shortage sensor.
•	Purpose: Detect ISE Reference Electrolyte, ISE Diluent and ISE Internal Standard after degasser.
•	Trigger conditions: Reagent low/short, air in line, degasser/tubing problem.
•	Failure symptoms: ISE reagent alarms, unstable ISE results.
•	Maintenance: Reagent prime, inspect reagent bottles/tubing.
Photometer Detection
•	Sensor type: Optical absorbance detection.
•	Purpose: Measure cell blank and reaction absorbance.
•	Trigger conditions: Lamp/output abnormality, dirty cell, optical drift.
•	Related alarms: Cell blank abnormality, photometric data alarms.
•	Maintenance: Photometer Check, Cell Blank Measurement, lamp replacement.
RFID Readers
•	Sensor type: Radio-frequency identification.
•	Purpose: Identify reagent packs/cassettes.
•	Trigger conditions: Pack handling, loading, registration.
•	Failure symptoms: RFID reading error, reagent registration stopped.
•	Diagnostics: Reagent Loader Check.
Cover Interlock Sensors
•	Sensor type: Safety switch/interlock.
•	Purpose: Detect and lock covers during operation.
•	Trigger conditions: Cover open, unable to lock cover.
•	Failure symptoms: Operation blocked, safety alarm.
•	Safety impact: Prevents injury from fast-moving mechanisms.

7. CALIBRATION PROCEDURES

ISE Calibration
•	Purpose: Calibrate Na⁺/K⁺/Cl⁻ electrode response.
•	Required consumables: ISE Standard Low, ISE Standard High, ISE S3 as applicable; ISE Internal Standard, Diluent, Reference Electrolyte.
•	Required conditions: Valid electrodes, no air in sipper line, sufficient reagents, clean dilution vessel.
•	Process: Request recommended calibration/QC, load calibrators, measure calibrators, review status.
•	Failure conditions: IStd.E, ISE.E, ISE.N, insufficient sample, clot, unstable electrode response.
•	Affected systems: Electrode block, reference electrode, sipper syringe, dilution vessel.
Photometric Test Calibration
•	Purpose: Generate valid calibration curve/K-factor for cobas c tests.
•	Required consumables: Calibrators, reagent cassette/pack, QC material.
•	Required conditions: Clean reaction cells, stable photometer lamp, valid reagent lot/pack.
•	Failure conditions: Dup.E, Diff.E, linearity/calibrator duplicate limits, poor photometer output.
•	Affected systems: Sample/reagent pipetting, reaction cells, photometer, reagent disk.
Immunology Calibration
•	Purpose: Establish assay response for e 801/e 602 tests.
•	Required consumables: Assay-specific calibrators, reagent packs, ProCell/CleanCell, AssayTip/AssayCup.
•	Required conditions: Valid reagent pack registration, clean sipper paths, sufficient consumables.
•	Failure conditions: Reagent pack handling errors, sipper LLD errors, calibration alarm.
•	Affected systems: Reagent manager, sample/reagent pipetters, sipper station, detection unit.

8. MAINTENANCE PROCEDURES

Daily / Pre-routine
•	Objective: Prepare instrument for routine operation.
•	Tasks: Logon, check system alarms, check photometer report, check water splashes, check syringes/tubing, perform software-controlled maintenance, clear sample database, load/unload reagents, download parameters, perform recommended calibration/QC, measure samples.
•	Affected systems: All modules.
•	Failure symptoms: Startup delay, alarms, calibration/QC failure.
Software-controlled Maintenance
•	Objective: Automated maintenance executed by instrument.
•	Examples: Photometer Check, Cell Blank Measurement, Incubation Water Exchange, Air Purge, Wash Reaction Parts, Reagent Prime, Cell Detergent Prime.
•	Expected results: Stable optical/fluidic performance and reduced carryover/air.
•	Failure symptoms: Maintenance incomplete, module unavailable, reagent/solution insufficient.
Manual Cleaning
•	Objective: Allow operator to clean probes/mechanical parts safely.
•	Mechanism: Motors of selected c 701/c 702/c 502/e 801/e 602 modules are switched off; e 801 sipper turntables move down and rotate 180° clockwise.
•	Post-condition: For c 701/c 702, reagent registration is required after manual cleaning.
c 701/c 702/c 502 Maintenance
•	Daily/weekly/monthly/quarterly/6-month/as-required: Documented separately for c 701/c 702 and c 502.
•	Key tasks: Reaction cell wash, incubation bath cleaning, photometer lamp replacement, aspiration filter cleaning, reaction cell replacement.
ISE Maintenance
•	Intervals: Daily, weekly, monthly, every 2 months, quarterly, every 6 months and as required for cobas 8000 ISE.
•	Key tasks: Probe cleaning, electrode replacement, reagent prime, ISE system wash, vacuum pump check on ISE neo.
e 801/e 602 Maintenance
•	Intervals: Daily, every 2 weeks, quarterly/as-required depending on module.
•	Key tasks: Clean aspiration pipes, consumables drawer, cooling filter, sipper flow paths, ProCell/CleanCell/PreClean paths.

9. ERROR CODES AND TROUBLESHOOTING

Liquid Level Sensor Alarm
Description
Liquid level sensor voltage is too low; the system generates a liquid level sensor alarm and the sample probe mechanism may remain in vertical upper position.
Trigger Conditions
•	Low LLD voltage.
•	Probe contamination.
•	Poor liquid contact.
•	Wiring/sensor defect.
•	Insufficient sample/reagent.
Possible Causes
1.	Dirty or wet probe surface.
2.	Air/liquid path issue.
3.	Insufficient liquid volume.
4.	Sensor circuit degradation.
5.	Cable/connector issue.
Affected Modules
ISE, c 503/cobas c modules, sample pipetting systems.
Diagnostic Procedure
1.	Check displayed system alarm and affected pipetter.
2.	Inspect sample/reagent level.
3.	Clean probe.
4.	Check for foam, bubbles, clots.
5.	Repeat check/maintenance.
6.	Escalate to Roche Service if persistent.
Recommended Corrective Actions
1.	Clean probe and remove contamination.
2.	Re-run liquid level check.
3.	Replace probe if damaged.
4.	Inspect tubing/syringe.
5.	Service sensor electronics if unresolved.
Severity
High.
Safety Impact
Possible probe movement and biohazard exposure; follow PPE and maintenance mode rules.

ISE.E / ISE.N Data Alarm
Description
ISE module test data alarm; indicates abnormal ISE measurement validity.
Trigger Conditions
•	Electrode instability.
•	Reagent shortage/air.
•	Reference electrolyte issue.
•	Internal standard abnormality.
Possible Causes
1.	Air in sipper syringe/path.
2.	Dirty dilution vessel/electrode.
3.	Expired/degraded electrode.
4.	Reagent problem.
5.	Pinch valve/sipper issue.
Affected Modules
ISE module / ISE v1 / ISE neo.
Diagnostic Procedure
1.	Check ISE reagents and liquid short sensors.
2.	Inspect sipper syringe/path for air.
3.	Perform reagent prime.
4.	Run ISE calibration and QC.
5.	Review electrode status.
Recommended Corrective Actions
1.	Prime ISE reagents.
2.	Clean dilution vessel/probe.
3.	Replace affected electrode/reference electrode.
4.	Repeat calibration/QC.
5.	Contact Roche Service if persistent.
Severity
High.
Safety Impact
Incorrect electrolyte results if not resolved.

IStd.E Calibration Alarm
Description
ISE Internal Standard-related calibration alarm.
Trigger Conditions
•	Internal standard signal abnormal.
•	ISE IS reagent path issue.
•	Electrode/reference instability.
Possible Causes
1.	Low/expired ISE Internal Standard.
2.	Air after degasser.
3.	Sipper or syringe malfunction.
4.	Electrode degradation.
Affected Modules
ISE module.
Diagnostic Procedure
1.	Check IS bottle, tubing and liquid short sensor.
2.	Perform ISE Reagent Prime.
3.	Inspect for bubbles.
4.	Repeat ISE calibration.
5.	Check electrode status.
Recommended Corrective Actions
1.	Replace/refill reagent.
2.	Prime path.
3.	Clean/replace tubing/probe/electrode as applicable.
Severity
High.

Cell Blank Abnormality
Description
Reaction cell blank deviation; if a reaction cell differs by more than 0.1 absorbance units from reaction cell no. 1, it is listed in the cell blank measurement report.
Trigger Conditions
•	Dirty/scratched reaction cell.
•	Photometer instability.
•	Water contamination.
•	Incubation bath contamination.
Possible Causes
1.	Dirty reaction cell.
2.	Cell aging/damage.
3.	Wash failure.
4.	Lamp/photometer issue.
Affected Modules
c 701, c 702, c 502.
Diagnostic Procedure
1.	Run Cell Blank Measurement.
2.	Identify listed cells.
3.	Perform Wash Reaction Parts.
4.	Replace reaction cells if persistent.
5.	Run Photometer Check.
Corrective Actions
1.	Clean cells.
2.	Replace reaction cells.
3.	Clean incubation bath.
4.	Replace photometer lamp if required.
Severity
Medium to High.

Reagent Loader / RFID Reading Error
Description
Reagent loader or RFID reader fails to process reagent pack/cassette.
Trigger Conditions
•	Reagent pack loading.
•	Reagent registration.
•	Reagent loader movement.
Possible Causes
1.	Pack incorrectly loaded.
2.	RFID read failure.
3.	Loader obstruction.
4.	Sensor failure.
5.	Reagent pack deformation.
Affected Modules
e 801; cobas pro e 801 reagent manager.
Diagnostic Procedure
1.	Check reagent loader status indicators.
2.	Remove/reload reagent pack.
3.	Perform Reagent Loader Check.
4.	Perform Reagent Handling Check if required.
5.	Review alarm description and remedy.
Corrective Actions
1.	Correct pack loading.
2.	Clean/check loader path.
3.	Use new pack if damaged.
4.	Contact Roche Service for RFID/sensor failure.
Severity
Medium to High.

General Instrument Problem
Description
Problem may be electrical/electronic, mechanical, operator-related, facility-related or computer-related.
Trigger Conditions
•	Alarms during operation.
•	Abnormal QC/calibration/sample results.
•	Environmental or utility instability.
Possible Causes
1.	Application/reagent/sample/calibrator/QC issue.
2.	Mechanical misalignment.
3.	Electronic or sensor fault.
4.	Heat/humidity/power/water/drain issue.
5.	Incorrect parameters or operator input.
Diagnostic Procedure
1.	Observe and record alarms.
2.	Isolate problem area according to alarms.
3.	Check application/reagent/sample/QC/calibrator.
4.	Check maintenance status and mechanical alignment.
5.	Check facility utilities.
6.	Escalate electrical/PCB issues to Roche Service.
Severity
Variable.

10. REPLACEMENT PARTS AND COMPONENTS

•	Sample probes: Aspirate/dispense samples; replace after clogging, damage, persistent pipetting/LLD/clot errors; calibration/QC verification required after replacement.
•	Reagent probes: Dispense reagents; replace if bent, clogged, contaminated, or carryover persists; affected tests require QC/calibration verification.
•	ISE electrodes Na/K/Cl: Measure ion potentials; replace if expired, unstable or calibration repeatedly fails.
•	ISE reference electrode: Provides reference potential; replace if reference instability or repeated ISE calibration failure.
•	Reaction cells: Photometric reaction vessels; replace if dirty/scratched or cell blank abnormal.
•	Photometer lamp: Optical light source; replace when output unstable or lamp maintenance required.
•	ProCell/CleanCell cups: e-module fluid cups; replace during e 801/e 602 maintenance when worn/contaminated.
•	AssayTip/AssayCup magazines: e-module consumables; replace/load as needed.
•	Aspiration filters/tubing: Replace/clean when blockage, pressure instability or reagent flow failure occurs.
•	Cooling unit filter: e 801 maintenance item; clean/replace if cooling airflow restricted.

11. FLUIDIC SYSTEMS

ISE Fluidics
•	Flow logic: IS/DIL/REF from reagent bottles through syringes/degasser/nozzles into dilution vessel/electrode block; sipper syringe aspirates diluted sample or IS, then reference electrolyte through reference electrode.
•	Key components: IS syringe, DIL syringe, sample syringe, sipper syringe, dilution vessel, electrode block, pinch valve, degasser, liquid short sensor.
•	Contamination risks: Dirty dilution vessel, electrode carryover, reagent degradation.
•	Blockage symptoms: ISE.E/ISE.N, low IS, unstable calibration, air in sipper.
•	Maintenance: Reagent prime, system wash, probe/dilution vessel cleaning, electrode replacement.
Clinical Chemistry Fluidics
•	Flow logic: Sample/reagent pipetted into reaction cells; ultrasonic mixing; incubation; photometric measurement; cell washing with CellCln/NaOHD/ECO-D.
•	Key components: Sample/reagent probes, syringes, reaction cells, mixers, incubation bath, wash nozzles.
•	Blockage symptoms: Poor precision, high/low results, cell blank abnormalities, pipetting alarms.
•	Maintenance: Air Purge, Wash Reaction Parts, Cell Detergent Prime, Incubator Bath Cleaning.
Immunology Fluidics
•	Flow logic: Sample/reagent/particles handled in AssayCup; PreClean/ProCell/CleanCell support pre-wash and ECL detection; sipper moves liquids to detection path.
•	Key components: PreClean aspiration tubes/nozzles, ProCell/CleanCell syringes, sipper nozzles, PC/CC cups, reagent probes.
•	Blockage symptoms: Reagent short sensor alarms, sipper check failure, low signal, QC drift.
•	Maintenance: Reagent Prime, sipper flow path cleaning, aspiration pipe cleaning.

12. SAFETY SYSTEMS AND WARNINGS

•	Operator qualification: Operators must not perform operation/maintenance without Roche-certified training; service not described must be left to Roche Service.
•	PPE: Eye protection, fluid-resistant lab coat, approved gloves and face shield when splash risk exists.
•	Biohazard: System mechanisms and waste may be infectious; decontamination required before reuse/recycling/disposal.
•	Mechanical safety: Interlocked covers prevent access to fast-moving parts.
•	Electrical/electronic safety: Operators must not remove PCBs unless instructed by Roche Service.
•	Software/data security: Unauthorized access and malware can cause data loss or render the system unusable; only authorized devices/software should be used, storage media secured, and backups performed regularly.
•	Reagent/chemical exposure: Direct contact with reagents/wash solutions may cause irritation, inflammation or burns; PPE and IFU precautions required.

13. SYSTEM INTERACTION MAP

•	Sample probe → pressure sensor → clot detection → sample/calibration validity.
•	LLD sensor → sample/reagent pipetter movement → aspiration success → alarm generation.
•	ISE liquid short sensor → IS/DIL/REF availability → electrode measurement stability.
•	Degasser → ISE reagent gas removal → EMF stability → ISE calibration/QC.
•	Photometer lamp → cell blank measurement → photometric assay reliability.
•	Reaction cell cleanliness → absorbance baseline → cell blank report → QC/sample accuracy.
•	Maintenance pipe → module maintenance actions → startup readiness.
•	Reagent RFID reader → reagent registration → reagent availability → calibration/test execution.
•	Interlock cover sensor → module power/motion enable → operator safety.

14. COMMON FAILURE PATTERNS

Pressure / Clot / Aspiration Instability
•	Symptoms: Clot alarms, insufficient sample, failed calibration, poor precision.
•	Likely causes: Probe clogging, bubbles, syringe leak, tubing restriction.
•	Affected systems: Sample pipetter, ISE, c modules, e modules.
•	Preventive actions: Probe cleaning, Air Purge, tubing/syringe inspection.
Calibration Drift
•	Symptoms: Calibration failure, QC drift, high/low results.
•	Likely causes: Reagent degradation, dirty cells/probes, electrode aging, lamp drift.
•	Affected systems: ISE, photometric, immunology.
•	Preventive actions: Scheduled calibration/QC, reagent control, cell blank/photometer checks.
Contamination / Carryover
•	Symptoms: Unexpected high/low results, QC failure, poor reproducibility.
•	Likely causes: Dirty probes, insufficient wash solution, reaction cell contamination.
•	Affected systems: c modules, ISE dilution vessel, e sipper paths.
•	Preventive actions: Wash Reaction Parts, Cell Detergent Prime, probe/sipper cleaning.
Sensor Degradation
•	Symptoms: LLD low voltage, reagent short alarms, RFID failures, interlock alarms.
•	Likely causes: Dirty sensor surfaces, cable/connector issues, electronic degradation.
•	Affected systems: Pipetting, reagent loading, cover safety, ISE reagent monitoring.
•	Preventive actions: Cleaning, diagnostic checks, Roche Service escalation.
Fluidic Blockage / Air in Lines
•	Symptoms: Reagent short, unstable ISE, poor precision, sipper alarms.
•	Likely causes: Air after degasser, clogged tubing/nozzle, empty reagent, filter blockage.
•	Affected systems: ISE, e module sipper/pre-wash, c module wash paths.
•	Preventive actions: Reagent Prime, Air Purge, aspiration filter cleaning, tubing inspection.
Mechanical Alignment / Loader Failure
•	Symptoms: Reagent handling failure, probe movement alarm, rack/pack loading error.
•	Likely causes: Misalignment, obstruction, worn gripper/loader, interlock misuse.
•	Affected systems: Reagent loader, sample/reagent pipetters, magazine gripper/lifter.
•	Preventive actions: Maintenance checks, manual cleaning mode, do not force moving parts.
Thermal / Incubation Instability
•	Symptoms: QC drift, photometric result deviation, reagent instability.
•	Likely causes: Incubation bath issue, cooling filter obstruction, facility heat/humidity.
•	Affected systems: c modules, e reagent cooling, facility utilities.
•	Preventive actions: Incubation Water Exchange, incubator bath cleaning, cooling filter cleaning, facility checks.

3. FAILURE RELATIONSHIP ANALYSIS

Dependency Chain 1 — Sample Fluidics → Pressure/LLD → Clot/Short/Precision
Sample probe, syringe, tubing, LLD ve pressure sensor aynı aspirasyon olayını farklı açıdan izler. LLD sıvı yüzeyini algılayamazsa sample short veya LLD alarmı; pressure profili bozulursa clot; syringe içinde bubble/leak varsa poor reproducibility oluşur. Bu zincir hem numune sonuçlarını hem calibration/QC tekrarlarını etkiler.
Dependency Chain 2 — ISE Reference Path → All ISE Tests
ISE Reference Electrolyte path ve reference electrode tüm ISE testlerinin ortak referansıdır. Bu nedenle reference path air bubble/crystallization veya reference electrode fault tüm Na/K/Cl ölçümlerini etkiler. Tek electrode arızası ise yalnız ilgili iyonu etkiler. Kılavuz, every ISE test probleminde reference path crystallization, prime, drain port cleaning ve electrode replacement adımlarını önerir.
Dependency Chain 3 — Reagent Stability → Calibration → QC Drift → Result Bias
Reagent expired, onboard stability over, reagent temperature out of range ve reagent deterioration; önce calibration kalite kriterlerini, sonra QC drift’i, sonunda sample result bias’ını tetikler. Reagent tracking software alarm üretse de alarm olmadan QC drift görülebilir.
Dependency Chain 4 — Thermal Control → Reaction Kinetics → Linearity/Sensitivity
Incubator/reagent/wash buffer temperature sapmaları photometric ve immunological reaction kinetics’i değiştirir. Bunun sonucu >Lin, >Kin, Sens.E, QC drift veya high/low results olabilir.
Dependency Chain 5 — Reagent Loader Mechanics → RFID/Registration → e 801 Test Availability
e 801 reagent loader path, RFID reader, pack position sensor ve reagent database registration birbirine bağlıdır. Mechanical pack handling failure, reagent registration stopped durumuna ve e 801 testlerinin kullanılamamasına neden olur.
Dependency Chain 6 — Control Unit UI → System Operability → Safe Shutdown
Frozen UI, doğrudan analitik ölçüm hatası olmayabilir; ancak operator control kaybı ve uygunsuz hard reset PC damage riskini yaratır. Bu nedenle safety shutdown prosedürü bir yazılım arızası için güvenlik katmanıdır.

4. MOST CRITICAL FAILURE PATTERNS

1. ISE Reference/Electrode Instability
Kritik çünkü tek reference path arızası tüm ISE testlerini etkileyebilir. Yanlış elektrolit sonucu klinik olarak yüksek risklidir. En güçlü göstergeler ISE.E, ISE.N, IStd.E, Slop.E, erratic ISE results ve ISE Check EMF instability’dir.
2. Sample Aspiration Chain Failure
Samp.C, Samp.S, LLD alarmı ve poor reproducibility aynı aspirasyon zincirinden gelir. Probe, syringe, pressure sensor, LLD ve tubing birlikte değerlendirilmelidir. Tek tek alarm temizlemek yerine bütün aspirasyon zincirini kontrol etmek gerekir.
3. Calibration Quality Criterion Failures
Cal.E, Dup.E, SD.E, Sens.E, Diff.E, S1A.E, Slop.E gibi alarm grubu testin matematiksel temelini invalid kılar. Kalibrasyon başarısızken sonuç üretmek servis açısından kabul edilemez.
4. Reagent Temperature/Stability Failures
ReagEx, OBS.RR/OBS.RM, Reag.T, WB.T ve Inc.T reagent/thermal stability sorunlarıdır. Alarm olmadan QC drift de üretebilirler. Bu arızalar doğrudan result bias üretir.
5. e 801 Reagent Loader/Pack Handling
Mekanik + sensor + RFID + software registration birlikte çalışır. Loader problemi sadece mekanik değildir; reagent availability, calibration, QC ve throughput’u etkiler.
6. UI Freeze / Unsafe Restart
Analitik bir data alarm değildir ama tüm sistem kontrolünü etkiler. Hard reset PC hasarı ve recovery süresi riskini artırır; safety shutdown prosedürü uygulanmalıdır.

5. PREVENTIVE ENGINEERING RECOMMENDATIONS

Calibration instability azaltma
•	Calibration öncesi reagent status, expiry, onboard stability ve temperature kontrol edilmeli.
•	Calibrator/QC material açıkta uzun süre bırakılmamalı.
•	Failed calibration sonrası sadece kalibrasyonu tekrar etmek yerine alarm tipine göre pipetting, detector, reagent ve material zinciri kontrol edilmeli.
Contamination azaltma
•	Sample/reagent probes, wash stations, ISE flow path, e 801 aspiration pipes ve sipper paths düzenli temizlenmeli.
•	Carryover şüphesinde special wash rules güncelliği doğrulanmalı.
•	Fibrinli, köpüklü veya partiküllü numune yüklenmemeli.
Pressure/fluidic failure azaltma
•	Syringe bubble/leak günlük gözlenmeli.
•	ISE reagent prime ve flow path wash trend bazlı uygulanmalı.
•	Tubing kink/occlusion, salt buildup ve crystallization bakım sırasında özellikle kontrol edilmeli.
Motor/mechanical wear azaltma
•	Reagent loader, mixer, pipetter arm ve rack transport alanlarında yabancı cisim/kir birikimi engellenmeli.
•	Reagent pack deformasyonu olan pack’ler kullanılmamalı.
•	Loader status indicator flashing durumunda mekanizmaya zorla müdahale edilmemeli.
Sensor degradation azaltma
•	LLD probe yüzeyleri temiz/kuru tutulmalı.
•	Barcode/RFID reader surfaces temizlenmeli.
•	Temperature sensor alarm trendleri HVAC ve fan/filter temizliğiyle birlikte izlenmeli.
Tubing blockage azaltma
•	ISE reference path crystallization kontrol edilmeli.
•	Drain port ve waste line temizliği planlı yapılmalı.
•	Reagent/wash solution bottles stabil koşullarda saklanmalı.
Electronic/software instability azaltma
•	Control unit/data manager için düzenli backup yapılmalı.
•	UI freeze durumunda safety shutdown uygulanmalı; hard power-off yapılmamalı.
•	Software update ve board-level müdahaleler Roche Service desteğiyle yapılmalı.
Thermal drift azaltma
•	Oda sıcaklığı 18–32 °C aralığında tutulmalı; WB.T remedy bunu doğrudan vurgular.
•	Rear fans unobstructed olmalı.
•	Cooling unit filters temizlenmeli.
•	Reagent temperature alarms sonrası QC/calibration verification yapılmalı.

ISE hattında Na/K/Cl elektrotları ve referans elektrot birlikte çalıştığı için bir elektrot sapması, sipper aspirasyon problemi veya nozzle kirlenmesi kalibrasyon eğrisini bozabilir. Medium	Tubing çıkması, yıpranması veya hat içi akış bozukluğu	Fluidic
Medium	Bakım sonrası kalibrasyon-kontrol doğrulamasının eksik veya başarısız olması	Maintenance

1.	Sipper probe, vacuum nozzle ve elektrot bloğu temizliği

4.	Reagent prime
5.	ISE check

4. HIGH-RISK RECURRING PATTERNS
1. ISE hattı kronik zayıf nokta
ISE olayları sadece “kalibrasyon geçmedi” olarak okunmamalı. Kapanışlar, sorunun çoğunlukla kirlenme + elektrot slope + solüsyon + tubing zincirinde olduğunu gösteriyor. Bu nedenle ISE için ayrı “önleyici bakım skoru” tutulmalı.
2. Mayıs 2026’da utility/su problemi kümelenmesi
Mayıs ayında su/tank kaynaklı olaylar belirgin artmış. Bu cihaz arızası değil, tesis altyapısı riski gibi ele alınmalı. Tek tek cihaz kaydı açmak yerine facility incident olarak kök neden takibi yapılmalı.
3. Reagent loading kayıtlarının bir kısmı servis arızası değil, kit süreç olayı
“Kit imhaya gönderildi” ile kapanan kayıtlar cihaz tamir bilgisinden çok kit yaşam döngüsü / stok / kullanıcı işlemibilgisidir. Bunlar teknik arıza havuzundan ayrı raporlanmalı.
4. Probe arızaları az ama duruş etkisi yüksek
Probe kırığı veya mekanik ayarsızlık doğrudan cihazı durdurur. Probe olaylarında “temizlikle geçti” ve “parça değişti” ayrımı net tutulmalı.

- failure_key: REAGENT_LOADING_KIT_HANDLING
  trigger_terms:
    - "reagent loading error"
    - "reagent loader"
    - "cihazdan çıkan kit"
    - "kit imhaya gönderildi"

6. OPERATIONAL RECOMMENDATIONS
1.	ISE için haftalık “electrode-health” takibi kurulmalı.
Her ISE olayında Na/K/Cl slope, değişen elektrot, sipper/nozzle temizlik tarihi ve kullanılan solüsyon lotu ayrı alan olarak kaydedilmeli.
2.	“Kit imha / reagent loading” kayıtları teknik servis arızasından ayrılmalı.
Bunlar ayrı bir “reagent logistics incident” kategorisine alınırsa gerçek cihaz arıza oranı daha doğru görünür.
3.	Mayıs 2026 su/tank olayları için tesis bazlı CAPA açılmalı.
Cihaz bazlı müdahale yerine merkezi su besleme, tank seviye alarmı ve sorumluluk zinciri gözden geçirilmeli.
4.	Probe arızalarında kapanış açıklaması zorunlu standardize edilmeli.
“Müdahale edildi, cihaz faal” gibi kısa kapanışlar bilgi kaybı yaratıyor. Minimum kapanış formatı: fiziksel bulgu + yapılan işlem + değişen parça + doğrulama sonucu.
5.	Pressure sensor olaylarında gerçek sensör arızası ile fluidic tıkanma ayrılmalı.
Eğer probe sıcak su/yıkama/hava alma ile düzeliyorsa kategori “sensor fault” değil, “fluidic restriction / air in line” olmalı.
6.	Tekrarlayan modül analizi düzenli yapılmalı.
İlk sınıflandırmaya göre LINE 4, LINE 7, LINE 2 ve ACIL kayıt yoğunluğu yüksek görünüyor. Bu hatlarda ayrı MTBF/tekrar arıza izleme yapılmalı.

7. EXECUTIVE ENGINEERING CONCLUSION
Bu veri seti cihazların en zayıf noktasının tek bir parça değil, ISE fluidic-sensor-maintenance zinciri olduğunu gösteriyor. En değerli teknik bilgi kapanış açıklamalarında: teknisyenler ISE problemlerini çoğunlukla sipper/nozzle/elektrot bloğu temizliği, elektrot değişimi, solüsyon yenileme, reagent prime, ISE check ve kalibrasyon-kontrol doğrulamasıyla çözmüşler. 
İkinci ana risk alanı mekanik hareket sistemleri: probe up/down, sample probe ayarı, tip-cup gripper, magazine lifter ve reagent bottle shift olayları cihaz duruşuna doğrudan etki ediyor. Reagent loading kayıtlarının önemli kısmı ise cihaz tamir bilgisinden çok kit yönetimi/imha süreci olarak ayrıştırılmalı.
Mayıs 2026’da utility/su besleme kaynaklı olayların artması, cihaz içi arızadan bağımsız bir tesis altyapı riski olduğunu düşündürüyor. Bu nedenle teknik servis raporlamasında “cihaz arızası”, “aplikasyon/kalibrasyon”, “kit/stok süreci” ve “facility kaynaklı stop” kesin olarak ayrılmalıdır.
